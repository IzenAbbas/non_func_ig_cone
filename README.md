# Instagram UI Clone - Dragon Ball Edition

A frontend-only Instagram clone built with Flutter, recreating the layout and user interface of Instagram with a custom Dragon Ball theme throughout the feed, profile, and app icon.

## Live Demo

**Web Demo:** [https://lnkd.in/dBF89hqt](https://lnkd.in/dBF89hqt)

**GitHub Repository:** [https://lnkd.in/deQF2vRj](https://lnkd.in/deQF2vRj)

## Overview

This project focuses on the UI/UX aspects of Instagram, demonstrating Flutter layout techniques and component composition. The interface features a Dragon Ball theme while maintaining Instagram's familiar design patterns.

## Features

- Home feed with Dragon Ball themed posts and stories
- Reels screen with short-form video content UI
- Profile screen with detailed user information
- Custom Dragon Ball themed app icon
- Responsive design for multiple screen sizes

## Getting Started

**Prerequisites:**
- Flutter SDK (3.0 or higher)
- Dart SDK

**Installation:**

```bash
git clone https://lnkd.in/deQF2vRj
cd non_func_ig_cone
flutter pub get
```

**Run the app:**

```bash
# Web
flutter run -d chrome

# Mobile
flutter run
```
